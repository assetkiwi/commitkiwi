# Roadmap

Planned, in no fixed order. Nothing here is promised for a particular release.

- **Forge API (optional).** A token stored in the system keychain, for pull/merge request lists, check status and
  checking out a request's branch. The current `gh`/`glab` integration stays the default and needs no token.
- **Linux desktop packages.** AppImage and/or `.deb`/`.rpm` builds; today Linux is "build from source" and the agent.
- **Updater.** Signed update checks; today there is no auto-update.
